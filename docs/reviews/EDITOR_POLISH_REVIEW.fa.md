# بازبینی انتخاب متن، جست‌وجو و ویرایش ساختاری

تاریخ: ۲۰۲۶-۱۰-۲۷

این مرحله از هشت مورد گزارش‌شده در تصاویر کاربر شروع شد و مسیرهای مرتبطِ ویرایش، ذخیره، بازیابی و صفحه‌کلید را نیز بررسی کرد. معیار پذیرش، ظاهر منسجم همراه با حفظ دقیق Markdown و امکان برگشت با Undo است. شواهد اجرای آزمون‌ها در `build/editor-polish/` قرار دارند؛ این پوشه خروجی تولیدی است و وارد Git نمی‌شود.

## یافته‌ها و اصلاح‌ها

| مسئله | اصلاح و معیار پذیرش |
| --- | --- |
| زمینهٔ ابزار قالب‌بندی در Write و Source متفاوت بود | حذف زمینهٔ ویژهٔ Write؛ مقایسهٔ رنگ محاسبه‌شدهٔ هر دو حالت در پوسته‌های روشن و تیره |
| انتخاب آوانگاری هنوز شکاف داشت | علامت‌های تکیهٔ `ˈ` و `ˌ` و چند علامت خنثی Spacing Modifier Letters در طبقه‌بندی فشردهٔ CodeMirror قویِ لاتین فرض می‌شدند. اصلاح محدود و محافظت‌شدهٔ همان طبقه‌ها؛ حفظ نویسه‌های واقعاً لاتین، حاشیه‌ها و جهت پاراگراف |
| رنگ انتخاب در بخش‌هایی آبی بود | یک توکن نارنجی برای انتخاب سند و انتخاب بومی در کادرها؛ لایهٔ بومی داخل CodeMirror شفاف می‌ماند تا انتخاب دوبار رنگ نشود |
| جست‌وجو بعد از اولین حرف تمرکز را می‌گرفت | انتخاب نتیجه بدون انتقال تمرکز؛ نمایش همهٔ تطبیق‌ها و نتیجهٔ جاری؛ Enter و Shift+Enter با گردش بین نتیجه‌ها |
| وضعیت جست‌وجوی بی‌نتیجه و جایگزینی روشن نبود | پیام بی‌نتیجه، غیرفعال‌شدن عملیات نامعتبر، باز و بسته‌شدن ردیف جایگزینی، شمارندهٔ دسترس‌پذیر و Escape محلی |
| ردیف جایگزینی روی متن می‌افتاد | حذف قاعدهٔ قدیمی grid که سطرهای واقعی ادیتور را بازنویسی می‌کرد؛ آزمون هندسی در عرض‌های ۱۴۴۰، ۶۸۰ و ۳۶۰ پیکسل |
| Ctrl+F/H در کادر جست‌وجو با صفحه‌کلید فارسی یکسان نبود | استفاده از حل‌کنندهٔ مشترک کلیدهای میان‌بر؛ آزمون KeyF و KeyH با نویسهٔ فارسی |
| تصاویر آنلاین همیشه مسدود بودند | کنترل «بارگیری تصاویر این میزبان» برای HTTPS؛ فعال‌سازی فقط با اقدام کاربر، اشتراک در همان سند و نشست بین Write، Read و پیش‌نمایش کناری، بدون تغییر Markdown؛ نمایش خطای قابل تلاش مجدد |
| برچسب تصویر در Read با Write فرق داشت | بازیابی متن جایگزین تصویر از Markdown و استفاده از کنترل مشترک تصویر |
| کلیک سلول جدول تمام سورس جدول را باز می‌کرد | ویرایش همان سلول با پیش‌نمایش قالب در پنجرهٔ کوچک؛ Tab و Shift+Tab بین سلول‌ها، Enter برای اعمال، Escape برای لغو؛ افزودن/حذف ردیف و ستون |
| سلول‌های خالی موقعیت ستون را از دست می‌دادند | استخراج مرز فیزیکی pipeها با رعایت escape؛ حفظ خانه‌های خالی، تراز، قالب درون‌خطی و پیشوندهای جدول تو‌در‌تو |
| اولین کلیک روی تب دیگر گاهی گم می‌شد | اعمال پیش‌نویس در مرحلهٔ capture رویداد click پس از تثبیت مسیر رویداد؛ آزمون تغییر تب با تنها یک کلیک |
| فرمول داخل سلول به ویرایش سورس کل جدول می‌رفت | گرفتن تعامل در سطح سلول پیش از کنترل فرمول؛ آزمون کلیک روی SVG واقعی ریاضی |
| Ctrl+Z بلافاصله بعد از اعمال سلول کار نمی‌کرد | عبور keydown از widget جدول به keymap بومی CodeMirror؛ آزمون کلید فیزیکی، مستقل از API فرمان ادیتور |
| پیش‌نویس سلول ممکن بود در ذخیره یا بازیابی جا بماند | flush صریح پیش از Save و ثبت recovery پنجره؛ بررسی محتوای دقیق فایل و snapshot بازیابی |
| بلوک کد مرز و کنترل روشن نداشت | بدنهٔ قابل ویرایش بومی، سربرگ زبان/کپی/ویرایش، مرز متعادل و نمایش درست بلوک خالی یا بسته‌نشده |
| کپی و ویرایش بلوک کد تو‌در‌تو می‌توانست علامت نقل‌قول را وارد کد کند یا ساختار را بشکند | تفکیک پیشوند ساختاری از بدنه؛ حفظ پیشوند نقل‌قول/فهرست هنگام ایجاد سطر خالی؛ آزمون کپی دقیق و Undo |
| آزمون بومی علامت `>` اضافی در بلوک کد خالی داخل نقل‌قول نشان داد | پنهان‌کردن پیشوند ساختاری در بدنه و سطر پایانی با حفظ فاصله‌های واقعی کد و عملگر مقایسهٔ `>`؛ آزمون متن DOM در حالت انتخاب‌شده و عادی |

ویرایش جدول فعلاً ویرایش Markdown یک سلول همراه با پیش‌نمایش است؛ سلول متنیِ غنی با تمام فرمان‌های سند نیست. Bold، Italic و Code روی همان سلول کار می‌کنند. کنترل‌های نامرتبط هنگام بازبودن ویرایشگر سلول نباید روی مکان‌نمای قدیمی سند اعمال شوند. ابزارهای سلول با Alt+F10 و سپس جهت‌نماها یا Home/End در دسترس‌اند؛ Escape از ابزارها به متن سلول بازمی‌گردد.

## محدودهٔ تصاویر آنلاین

تصاویر پیش‌تر به‌صورت پیش‌فرض و عمدی بارگیری نمی‌شدند. اکنون اقدام صریح کاربر، همان میزبان را فقط در همان سندِ باز و همان نشست فعال می‌کند؛ پیش از آن هیچ عنصر درخواست‌کنندهٔ تصویر ساخته نمی‌شود. درخواست تصویر Referer نمی‌فرستد. اعتبارسنجی، نشانی HTTPS عمومی‌نما را می‌پذیرد و نشانی محلی، IP مستقیم، credential و scheme نامعتبر را رد می‌کند؛ این اعتبارسنجی جایگزین resolver شبکه یا کنترل مقصد redirect نیست.

این قابلیت نمایش سند است. سیاست دریافت تصاویر در خروجی PDF همچنان از تنظیمات موجود موتور پیروی می‌کند. تصویر محلیِ مفقود مانند `./README.png` نیز باید کنار فایل Markdown وجود داشته باشد؛ بارگیری آنلاین جای آن فایل را نمی‌گیرد.

## روش راستی‌آزمایی

آزمون هندسی، محدودهٔ واقعی تک‌تک نویسه‌های انتخاب‌شده و انتخاب‌نشده را در مرورگر مقایسه می‌کند؛ صرفاً نبود خطا یا وجود یک کادر انتخاب کافی نیست. نمونه‌های عمومی شامل تکیهٔ آغازین IPA، فارسی/لاتین، شکست سطر، جهت انتخاب و تغییر عرض‌اند. فایل شخصی وارد مخزن یا گزارش عمومی نشده است.

آزمون‌های جدول علاوه بر واحدهای مستقل، در خود workspace اجرا می‌شوند: تعویض تب، Save واقعی از bridge آزمایشی، Source، Find، کلیدهای فیزیکی فارسی، Undo و بازیابی. تصاویر اینترنتی آزمون خودکار با پاسخ HTTPS کنترل‌شده بررسی می‌شوند تا نبود درخواست اولیه، تلاش مجدد و مرز سند به‌طور تکرارپذیر سنجیده شود. پذیرش Windows روی فایل و پروفایل اختصاصی آزمایش انجام می‌شود.

این شواهد دربارهٔ مسیرهای آزموده‌شده‌اند؛ تضمین نبود هرگونه اشکال در تمام اسناد ممکن نیست. انتشار GitHub، نصب‌کننده و updater بخشی از این مرحله نیستند.
